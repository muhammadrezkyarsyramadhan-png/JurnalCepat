Jurnal Generator (HTML/CSS/JS biasa, tanpa instalasi)

Cara pakai:
1. Ekstrak zip, klik dua kali index.html (terbuka di browser). Tidak perlu Node/npm.
2. Isi tanggal Mulai dan Akhir, lalu pilih yang dijalankan: Harian, Mingguan, atau Keduanya.
3. Atur toggle di tab Harian dan Mingguan (tab Mingguan: pilih hari, saksi, dan nama teman).
4. Klik "Salin script".
5. Buka https://app.kejar.id, login, tekan F12, buka tab Console.
6. Tempel script (kalau diblokir, ketik: allow pasting lalu Enter), tekan Enter.
7. Tunggu tulisan "selesai". Tanda ✅ berhasil, ⚠️ ditolak server.

Catatan:
- Pengaturan tersimpan otomatis di browser. Tombol Reset mengembalikan ke default.
- Habit mingguan yang di-set Tidak dicatat di hari bawaannya (pilihan hari hanya muncul saat Ya).
- Nama teman default kosong.
- Tanggal dihitung dalam UTC, jadi tidak bergeser 1 hari di WIB.
- Entri mingguan hanya dikirim untuk tanggal di dalam rentang Mulai-Akhir.
